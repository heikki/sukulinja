# Make the people a baptism names from its Roles

Spec: `../spec.md` (The card: People). ADR-0033.

A Role with no one in the tree takes _New …_: a name as the tree writes it, a sex for a child. Saved with the Entry: a new child into the named parents' family (new family if they aren't a couple), new parents with the child. Refused when no one named is in the tree yet. Goes through the Tree context's add/link operations, not a second way to add people.

Done when: a baptism with a new child, with new parents, and with all new (refused) is tested, and `bun dev` in dark mode from a New dataset's first person to their parents, with screenshots.
